# Holberton School - Shell & Bash Scripting

This repository contains a collection of shell scripts and exercises completed as part of the **Holberton School** curriculum. It covers fundamental Unix/Linux shell commands, permissions management, and input/output redirections.

---

## 📂 Project Directories

### 1. `basics`
Introduction to basic shell commands, file system navigation, file manipulation, and working in a Unix environment.

### 2. `permissions`
Scripts focused on file and directory access rights, mode changes, recursive permissions, and ownership management:
* Using `chmod`, `chown`, and `chgrp`.
* Managing symbolic links with `-h`.
* Setting conditional ownership with `--from`.
* Handling recursive and special permission flags (`+X`, `--reference`).

### 3. `io_redirections_and_filters`
Scripts exploring standard streams, redirection operators, and command-line text filters:
* Redirection operators (`>`, `>>`, `2>&1`).
* Text display and filtering tools (`cat`, `head`* Text d, `grep`, `wc`, etc.).
